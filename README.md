# StreamWeaver - High Troughput No-code ETL Pipeline
A web application that allows users to upload large CSV/JSON datasets. 
The application processes files by streaming them chunk-by-chunk, enables column mapping and data transformations, displays live progress, and performs bulk inserts of the cleaned data into MongoDB.
Its primary objective is to process large files efficiently without causing memory crashes.

# Tech stack
- React
- Node.js
- Express
- MongoDB
- Spcket.io
